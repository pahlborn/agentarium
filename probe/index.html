Agentarium Schlüssel-Probe

Darf der Browser einen GitHub-Schlüssel mitsenden? Davon hängt ab, ob Agentarium die goldene Variante ohne zusätzliche Geräte bekommt.

Noch nicht gemessen

Schlüssel eintragen und messen. Die Probe macht drei Abrufe bei GitHub und liest ab, was zurückkommt.

Messungen

  1. Ohne Schlüssel wartet
  2. Mit Schlüssel wartet
  3. Tempo, fünf Abrufe wartet

Woher der Schlüssel kommt

Auf GitHub: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Dort Only select repositories wählen und nur pahlborn/agentarium eintragen, bei den Rechten nur Contents: Read-only und Issues: Read-only.

Direkt: github.com/settings/personal-access-tokens/new

Was mit dem Schlüssel passiert

Er bleibt im Arbeitsspeicher dieser Seite und wird nicht gespeichert — nach dem Schließen ist er weg. Gesendet wird er an niemanden außer GitHub selbst. Widerrufen kannst du ihn jederzeit auf derselben GitHub-Seite.
